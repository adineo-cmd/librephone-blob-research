# inbox — desktop results land here

Drop W1-W5 result files here using the naming convention in
../WORKORDER-001-desktop.md. The lab agents poll this directory, distill
every submission to facts, and merge them into the coverage matrix and
docs. Raw payloads stay on the desktop; only inventories, hashes,
strings, facts files, and derived analysis artifacts (e.g. reference
WAVs) belong here.

Status notes: STATUS-<WO>.md for any halt/failure — honest negatives are
deliverables too.
