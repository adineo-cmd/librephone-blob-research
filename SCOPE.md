1. Uniqueness bar: verify the gap before claiming a finding (prior-art
   checks with dates).
2. Discover / reverse engineer / research — original work only.
3. **All of LibrePhone's blobs, cross-vendor**: Qualcomm (Fairphone FP6
   deep-dive, complete through boot chain) and MediaTek (starting).
4. Internet-wide scouting for fields needing contribution.
5. Famous GitHub projects as instruments (awesome lists, kernel sources,
   linux-firmware listings), never re-published.

7. Note everything, including negative results.
8. Excluded by owner: CVE hunting, classical-cipher cryptanalysis.
