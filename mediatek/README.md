# MediaTek front — opening

This directory is reserved for the MediaTek firmware research front
(same methodology as `qualcomm-fp6/`: architecture ID, segment maps,
version strings, prior-art checks). An agent is working on it now;
content will appear here as it lands.

Planned families (from public LineageOS builds):

- `md1img` (modem firmware)
- `sscp/scp` (system control processor)
- `mcupm`
- `spmfw`
- TEE
- connectivity
